# WebOS Desktop

浏览器中的类操作系统桌面环境，模拟真实桌面操作系统的交互体验。

## 功能

- 桌面图标与应用启动器
- 多窗口管理（最小化、最大化、关闭）
- 任务栏与系统托盘
- 窗口拖拽与层叠
- 深色主题

## 在线体验

👉 [yyh-0428.github.io/webos-desktop](https://yyh-0428.github.io/webos-desktop/)

## 技术栈

- React 19 + TypeScript
- Vite
- Tailwind CSS

## 本地开发

```bash
npm install
npm run dev
```
